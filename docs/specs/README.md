# Specs

Scoped, actionable specs produced by the `product-manager` subagent from rough requirements. Each file is one feature/change small enough for the `coder` subagent to implement in a single focused pass.

Naming: `<kebab-case-title>.md`, e.g. `bulk-retry-failed-jobs.md`.

Status values: `Draft` (open questions unresolved) → `Ready` (approved, unblocked for `coder`) → `Implemented` (shipped — leave the file as a historical record, don't delete).
