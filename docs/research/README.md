# Research

QA/testing-tooling research and feature suggestions produced by the `qa-strategist` subagent. Each file covers one topic and ends with concrete, flawferret2-specific suggestions (and things explicitly ruled out, so ideas aren't re-litigated from scratch later).

Naming: `<kebab-case-topic>.md`, e.g. `flaky-test-detection.md`.

A suggestion here that's worth building should get turned into a spec under `docs/specs/` via the `product-manager` subagent before `coder` touches it.
